# Film OS — מפת בסיס נקייה

מסמך זה מגדיר כיצד לנקות ולחדש את חוויית הפורטל בלי להחליף את מקור האמת או לאבד גרסאות.

## עקרון מנחה

הנתונים והחוזים הקיימים הם שכבת האמת. ה־UI הוא לקוח שניתן להחליף. כל פעולה משמעותית חייבת להמשיך להירשם דרך אותם חוזים: נכס קנוני, revision, בחירה פעילה, snapshot של prompt, quote, approval, run, review ו־delivery manifest.

## מה מאמצים מפרויקטי open source

| מקור | דפוס שאנו מאמצים | גבול האימוץ |
| --- | --- | --- |
| SPITE | Canvas/Flow מודרני, רפרנסים לפי שם, בחירת מודלים ועלות גלויה | השראה ארכיטקטונית בלבד בשלב הראשון; AGPL ופרויקט מוקדם |
| ShotBase | גרסאות בלתי־הרסניות, first/last frame, active version, provenance וייצוא | ניישם על הסכמות הקיימות שלנו; MIT |
| Video Studio | dry-run, מניעת חיוב כפול, שמירת כל הטייקים וחיבור manifest → MP4 | נשתמש במנוע שלנו וב־Worker המאובטח; MIT |
| StoryMind | CharacterSheet, עוגני רציפות ותכנון שוטים מובנה | נשתמש ברעיונות בסכמת ה־brief; לא נעתיק קוד AGPL |
| OpenMontage | בדיקות חוזה ותזמור pipeline | ניישם בדיקות ממוקדות, לא את כל המערכת |

## שלוש שכבות המוצר

1. **Truth layer** — D1/R2 והחוזים הקיימים. אין שינוי מזהים ואין דריסת נכסים.
2. **Orchestration layer** — adapters לספקים, קטלוג יכולות, quote/approval, jobs, retries ו־QC.
3. **Experience layer** — Command Center, Builder, Timeline, Review, Assets ו־Delivery.

## כללי גרסאות

- כל יצירה חדשה היא revision בלתי־מחיק.
- רק פעולה מפורשת של המשתמש מקדמת revision ל־active.
- וידאו חסום כאשר תמונת המקור הנדרשת אינה מאושרת.
- בחירת גרסה בטיימליין היא הבחירה שמופיעה ב־delivery manifest.
- prompt, negative prompt, מודל, קלטים ועלות נשמרים עם כל run.

## סדר מימוש

1. להפריד את נתוני הדמו והקטלוג ממסך הבית לקבצי registry טיפוסיים.
2. ליצור UI חדש בשלוש עמודות: ניווט, משטח עבודה, הקשר/פעולות.
3. לאחד את Review לתבנית אחת לתמונה ולווידאו עם checklist המתאים לסוג המדיה.
4. להוסיף קטלוג ספקים המבוסס על capabilities, ולא על שמות מודלים קשיחים בקומפוננטות.
5. להוסיף dry-run ואימות חוזה לפני כל פעולה מחויבת.
6. להפעיל בדיקות חוזה לזרימות: create → quote → approve → run → review → promote → deliver.

## קריטריון הצלחה

אפשר לבנות סרט חדש מאותו פורטל, לבחור דמות/אביזר/לוקיישן קיימים, לייצר מספר גרסאות, לקדם אחת, להרכיב cut ולהוריד תוצר — בלי לערוך קוד ובלי לאבד היסטוריה.
