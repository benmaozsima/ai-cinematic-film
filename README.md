# AI Cinematic Film Workspace

This workspace is the source of truth for the long-term AI cinematic film project.

Goal: reverse-engineer high-quality cinematic AI film methodology, then use the extracted production pipeline to create an original 5-8 minute cinematic short with a different story, world, characters, and visual identity.

Core principle: consistency matters more than impressive isolated shots.

## Current Phase

Original short pre-production: screenplay and shot lock for the approved 60-second, 9:16 Israeli comedy `The Search Party`.

The Red Alert 2 cinematic credited online to lyxw1327 / Douyin remains a methodology reference only. Its Phase 1 analysis is preserved; its creative content is not a source for the original short.

## Evidence Rules

Every claim should be classified as:

- Confirmed: directly supported by a source or frame evidence.
- Strong inference: highly likely based on visible evidence or repeated external reports.
- Speculation: plausible but unverified.

Do not move from methodology analysis into original creative development until Phase 1 deliverables are complete enough to extract a reusable pipeline.
