# AI Movie Creator

המסלול הפעיל של הפורטל הוא `production-portal/`. סביבת העבודה המקומית המלאה ליצירה, הפקה, בדיקת גרסאות וייצוא נמצאת ב־`frameforge-studio/`.

כדי להמשיך את סביבת Frameforge במחשב אחר, משכפלים את הענף השמור ומריצים מתוך התיקייה `frameforge-studio/` את `npm ci` ואז `npm run dev`. נתוני ההפקה והמדיה נשמרים מקומית ב־`studio-data/` ואינם נכנסים ל־Git; יש להשתמש ב־`npm run backup` כדי להעביר הפקות ומדיה בנפרד. מפתחות ספקים יש להגדיר מחדש במחשב היעד.

`legacy-dashboard/` נשמר כארכיון בלבד ואינו מופעל, נבנה או נפרס. הוא נשמר זמנית כדי לאפשר שחזור של חומר ישן בזמן המעבר לאפליקציה החדשה.

הפורטל החדש נבנה סביב שכבת מקור האמת של ההפקה, קטלוג capabilities לספקים, גרסאות בלתי־הרסניות, שערי אישור, ריצות רקע, QC ו־delivery.
